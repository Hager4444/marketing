# Hager Fawzy Yusuf · Portfolio

Public portfolio site for Hager Fawzy Yusuf, Senior Performance Marketing Specialist.

Live site: https://hager4444.github.io/marketing/

## Files

- `index.html` — the whole site. The page content (profile, case study, projects, tables and screenshot captions) is the JSON block inside `<script id="state">`.
- `shots/` — ad platform and analytics screenshots shown on the Campaigns page.
- `og.png` — the preview image shown when the link is shared on LinkedIn, WhatsApp or X.
- `robots.txt`, `sitemap.xml` — let search engines find and index the site.

## Updating

The page is edited in its Claude artifact (Edit portfolio → Save and publish). To bring those edits here, ask Claude to sync the site: it copies the latest artifact into `index.html`, adds any new screenshots to `shots/`, and updates `lastmod` in `sitemap.xml`.
